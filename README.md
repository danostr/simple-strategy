SIMPLE STRATEGY — PROJECT DOCUMENTATION
---

Description: A lightweight 3D grand strategy game focused on grand-scale 
simulation and map interactions, built as a streamlined, high-performance 
alternative to complex historical strategy titles.

### [TECHNICAL STACK]

* **Engine:** Unity 6.4 (6000.4.10f1)
* **Graphics:** Universal Render Pipeline (URP)
* **Language:** C#
* **Architecture:** ScriptableObject Data Layer + Color-Coded Texture Lookup
* **Source Control:** Git + Git LFS
